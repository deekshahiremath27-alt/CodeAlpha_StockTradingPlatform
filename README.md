# CodeAlpha Stock Trading Platform

A Java console application that simulates a basic stock trading environment.

## Features

- Display simulated stock market data
- Buy and sell stocks
- Track virtual cash balance
- Manage portfolio holdings
- Calculate portfolio market value
- Calculate profit and loss
- Record transaction history
- Record portfolio performance snapshots
- Save transactions to a local text file
- Uses Object-Oriented Programming concepts

## Technologies Used

- Java
- OOP
- Collections Framework
- File Handling
- Java Date and Time API
- Exception Handling
